# Просмотры сообществ VK

Расширение для Chrome, Яндекс Браузера и Orion на iPhone. Показывает просмотры по вашим сообществам ВКонтакте и их постам, а также доход из VK AdBlogger.

- Сумма просмотров и число постов за 7, 30, 90 дней или год.
- Сообщества с суммой просмотров, типичным постом (медианой) и заработком.
- Посты: сортировка, поиск по тексту, фильтр по сообществу и фильтр «Только AdBlogger».
- «К обычному»: во сколько раз пост обогнал типичный пост своего сообщества. Посты младше 2 дней не сравниваются, потому что ещё набирают просмотры.
- Доход AdBlogger по каждому посту: заработок, заработок на 1000 просмотров, прогноз и клики.
- На компьютере посты показаны таблицей, на телефоне карточками.

## Что лежит в репозитории

| Папка | Для чего |
|---|---|
| `extension` | Расширение для Chrome и Яндекс Браузера на компьютере |
| `orion/extension` | То же расширение для Orion на iPhone: у значка есть окно с кнопкой «Открыть статистику» |
| `dev` | Тесты и предпросмотр на условных данных |
| `tools/build.py` | Сборка `orion/extension` и архива для друга |

## Установка на компьютер

Порядок одинаковый в Chrome и Яндекс Браузере:

1. Скачайте репозиторий: кнопка **Code**, затем **Download ZIP**, и распакуйте его в постоянное место. Папку потом не перемещайте.
2. Откройте страницу расширений: `chrome://extensions` в Chrome или `browser://extensions` в Яндекс Браузере.
3. Включите режим разработчика.
4. Нажмите «Загрузить распакованное расширение» и выберите папку `extension`.
5. Нажмите на значок расширения, откроется дашборд.

## Установка на iPhone через Orion

Обычные Chrome и Яндекс Браузер на iPhone не поддерживают расширения, поэтому нужен браузер Orion.

1. Установите **Orion Browser by Kagi** из App Store.
2. В Orion нажмите **•••** внизу справа, откройте **Settings** и в группе **Extensions** включите расширения Chrome.
3. Скачайте этот репозиторий на iPhone: в Safari откройте страницу репозитория, нажмите **Code**, затем **Download ZIP**. Архив сохранится в приложение «Файлы».
4. В приложении «Файлы» нажмите на архив, чтобы он распаковался.
5. Найдите в распакованной папке папку `orion/extension`.
6. Создайте в «Файлах» папку `orion`, например в разделе «На iPhone», и переместите в неё папку `extension`. Должно получиться `orion/extension`.
7. В Orion нажмите **•••**, откройте **Extensions** и нажмите **+**.
8. Выберите **папку** `orion/extension`. Выбирайте именно папку, а не архив.
9. Разрешите расширению запрошенный доступ.
10. Нажмите на значок расширения и в окне нажмите **«Открыть статистику»**.

Если вкладка не открывается, нажмите **«Открыть в этом окне»**.

Скачать репозиторий можно и на компьютере, а папку `orion/extension` перенести на iPhone через iCloud Drive или AirDrop.

### Как обновить в Orion

1. Скачайте свежую версию репозитория и замените папку `orion/extension` на iPhone новой.
2. В Orion удалите старое расширение в **Extensions** и установите новое из той же папки.

После удаления расширение забывает свои настройки, поэтому ссылки на сообщества и вход придётся ввести заново.

### Что пока не проверено в Orion

Поддержка расширений в Orion на iOS по словам Kagi работает в бета-режиме. На iPhone проверено, что расширение ставится, а дашборд и карточки открываются. Вход через VK ID и данные AdBlogger на iPhone пока не проверялись. Если вход не сработает, вставьте ключ доступа в настройках расширения.

## Подключение аккаунта

### Через VK ID

1. Создайте приложение на [сайте VK ID](https://id.vk.ru/about/business/go). Вход туда идёт через VK Бизнес ID. Профиль бизнеса нужно подтвердить в течение 60 дней после создания первого приложения, иначе приложения заблокируют.
2. Откройте настройки расширения и вставьте ссылки на свои сообщества, по одной в строке.
3. Скопируйте адрес перенаправления из настроек расширения.
4. В приложении VK ID добавьте домен этого адреса в базовые домены, а сам адрес в доверенные.
5. Разрешите приложению доступ `wall`, если он есть в настройках. Право `groups` нужно только при пустом списке ссылок.
6. Укажите ID приложения в настройках расширения и нажмите «Войти через VK ID».

Адрес зависит от ID расширения. У распакованного расширения ID обычно зависит от папки, поэтому в другом браузере, на iPhone или после переноса папки адрес может быть другим. Тогда добавьте новый адрес в VK ID.

### Если VK ID не выдаёт нужные права

Документация VK пишет, что новому приложению VK ID сразу доступны базовые права, а часть расширенных выдаётся по согласованию. Запросить их можно по адресу devsupport@corp.vk.com. Права, выданные приложению раньше, сохраняются.

Если у вас уже есть ключ доступа с правом `wall`, вставьте его в настройках. Такой ключ не обновляется автоматически.

По документации `wall.get` можно вызывать и с сервисным ключом из настроек приложения. Для этого нужен список ссылок, а закрытые стены такой ключ может не прочитать. Сервисный ключ принадлежит приложению, поэтому не передавайте его другим и не добавляйте в репозиторий.

## VK AdBlogger

Нажмите «Загрузить AdBlogger» в шапке или просто откройте кабинет в том же браузере. Расширение сохранит заявки и свяжет их с постами по адресу поста.

- Своих запросов к AdBlogger расширение не отправляет. Оно копирует ответ `author/soco/placements`, который кабинет получил сам.
- Кнопка открывает кабинет в фоновой вкладке и закрывает её после сохранения заявок. Если за 20 секунд заявки не пришли, например нужен вход, вкладка становится активной.
- Дальше страницы уходят только нужные поля: без текстов постов, токенов маркировки и контактов.
- Способ неофициальный: запрос не документирован, а соответствие правилам платформы не подтверждено. Если кабинет изменится, доход перестанет обновляться, а просмотры продолжат работать.
- `predictedReward` приходит в рублях, это сверено с кабинетом. `sum100` и `cpm100` считаются копейками по аналогии с `price100`, но на реальных ненулевых значениях не сверены. Если суммы расходятся с кабинетом, правка находится в `extension/adblogger/parse.js`.

## Что нужно знать

- **Хранение данных.** Токены, статистика и данные AdBlogger лежат в хранилище браузера без шифрования и никуда, кроме VK, не отправляются. Кнопка «Выйти и удалить данные» стирает их.
- **Запросы.** Расширение делает около 3 запросов в секунду, как разрешает VK. Один запрос возвращает до 100 постов, поэтому много сообществ за год загружаются не мгновенно.
- **Смысл просмотров.** Сумма за период считает все просмотры постов, опубликованных в этот период, а не просмотры, набранные за него.
- **Посты без данных.** Если VK не вернул просмотры, стоит прочерк, а в сумму такой пост не входит.

## Разработка

Код правится только в `extension`. Папку `orion/extension` не редактируйте вручную: после изменений пересоберите её.

```bash
python tools/build.py
```

Скрипт обновит `orion/extension`, соберёт `dist/VkViews.zip` для друга и проверит, что все файлы на месте и в них нет ключей доступа.

Проверка без браузерного расширения и без аккаунта VK:

```bash
python -m http.server 5199 --bind 127.0.0.1
```

- `http://localhost:5199/dev/tests.html`: тесты логики.
- `http://localhost:5199/dev/preview.html`: дашборд на моковых данных.
- `http://localhost:5199/dev/preview.html?adblogger=1`: дашборд с условными заявками AdBlogger.
- `http://localhost:5199/dev/preview.html?state=welcome`: экран подключения.
- `dev/card-design.html`: все состояния карточки поста. Открывается и с диска.

Устройство кода:

- `extension/lib/auth.js`: вход VK ID (OAuth 2.1 + PKCE), обновление токенов.
- `extension/lib/vk-api.js`: запросы к API, лимит частоты, повторы.
- `extension/lib/group-links.js`: разбор ссылок на сообщества.
- `extension/lib/loader.js`: загрузка сообществ и постов.
- `extension/lib/stats.js`: расчёты без браузерных API.
- `extension/adblogger/*`: перехват ответа кабинета, разбор и сохранение заявок.
- `extension/dashboard.*`: интерфейс.
- `extension/popup.*`: окно расширения для Orion.
