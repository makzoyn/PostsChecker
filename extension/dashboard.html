Просмотры сообществ

Подключите аккаунт ВКонтакте

Расширение читает ваши сообщества и посты через VK API. Данные остаются в этом браузере.

  1. Создайте приложение на сайте VK ID.
  2. Добавьте адрес из настроек расширения в доверенные адреса перенаправления.
  3. Вставьте в настройках ссылки на свои сообщества, укажите ID приложения и войдите.

          Настройки

          Ваши сообщества

          Если оставить поле пустым, расширение попробует получить список само. Для этого нужно право groups.

          Вход через VK ID

          В настройках приложения VK ID добавьте домен этого адреса в базовые домены, а сам адрес в доверенные. Адрес должен совпадать полностью, включая косую черту в конце.

          Или готовый ключ доступа

          Такой ключ не обновляется сам: когда он истечёт, вставьте новый. Для сервисного ключа нужен список ссылок выше, а закрытые стены он может не прочитать.
